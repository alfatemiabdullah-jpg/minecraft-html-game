# 🎮 لعبة Minecraft - HTML

لعبة Minecraft بسيطة ومرحة مصنوعة بـ HTML و CSS و JavaScript!

## 🎯 المميزات

- 🎮 تحكم سهل باستخدام لوحة المفاتيح
- 🏗️ بناء وحفر البلوكات
- 📦 نظام حقيبة (Inventory)
- ❤️ نظام الصحة والجوع
- ⭐ نظام المستويات
- 💎 أنواع مختلفة من البلوكات (الذهب والماس والخشب وغيرها)
- 📱 متوافق مع الأجهزة المختلفة

## 🎮 طريقة اللعب

### التحكم:
| المفتاح | الفعل |
|--------|--------|
| **W** | الحركة للأعلى ⬆️ |
| **S** | الحركة للأسفل ⬇️ |
| **A** | الحركة لليسار ⬅️ |
| **D** | الحركة لليمين ➡️ |
| **E** | حفر البلوكات 🔨 |
| **R** | بناء البلوكات 🧱 |
| **Space** | الأكل 🍎 |

### قوائم اللعبة:
1. **الصحة ❤️**: تقل عند التعرض للضرر، قد تموت إذا وصلت إلى 0
2. **الجوع 🍖**: تقل مع الوقت، تحتاج للأكل لتجنب الضرر
3. **المستوى ⭐**: يزيد عند حفر أو بناء البلوكات
4. **الحقيبة 📦**: تخزين البلوكات التي تحفرها

### أنواع البلوكات:
- 🟩 **العشب (Grass)**: متوفر بكثرة
- 🟫 **التراب (Dirt)**: للبناء الأساسي
- ⬜ **الحجر (Stone)**: مادة بناء قوية
- 🪵 **الخشب (Wood)**: يمكن أكله للحصول على جوع
- 🌊 **الماء (Water)**: خطر! تجنبه
- ⭐ **الذهب (Gold)**: نادر وقيم
- 💎 **الماس (Diamond)**: نادر جداً!

## 📋 الهدف من اللعبة

1. ابقَ على قيد الحياة بالحفاظ على صحتك وجوعك
2. اجمع المواد النادرة (الذهب والماس)
3. ارفع مستويك بقدر الإمكان
4. تجنب الماء والضرر العشوائي

## 🚀 كيفية اللعب

1. افتح ملف `index.html` في متصفحك
2. استخدم مفاتيح WASD للتحرك
3. انقر على البلوكات المجاورة للحفر
4. استخدم R للبناء من مواد الحقيبة
5. استخدم Space لتناول الطعام من الخشب

## 💻 التقنيات المستخدمة

- **HTML5**: هيكل الصفحة
- **CSS3**: التصميم والرسومات والتأثيرات
- **JavaScript**: منطق اللعبة والتحكم

## 📝 الملفات

- `index.html` - الصفحة الرئيسية
- `style.css` - التصميم والرسومات
- `script.js` - منطق اللعبة
